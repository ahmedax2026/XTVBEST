# تشغيل XBest بالمعالج أو كارت الشاشة

من إعدادات بروفايل التحويل اختر CPU أو نوع GPU، ثم اختَر البروفايل في إعدادات القناة واحفظ. استخدم بروفايل مستقل لكل قناة تحتاج إعدادات مختلفة؛ تعديل بروفايل مشترك يؤثر على كل القنوات المرتبطة به. يتطبق التغيير عند بدء جلسة بث جديدة.

فعّل **Auto — GPU with CPU fallback** لاختيار كارت متوافق تلقائيًا. يجري السيرفر تجربة ترميز فعلية قصيرة بالصيغة وعمق اللون المحددين، ويجرب NVIDIA ثم Intel ثم VA-API على Linux، أو NVIDIA ثم Intel على Windows. على macOS يجرب VideoToolbox. عند فشل كل التجارب يستخدم CPU. يتشارك البث المتزامن نتيجة الفحص، وتُحفظ لمدة دقيقة لتجنب الفحص المتكرر.

في Auto مع محرك البث الأساسي، يفك CPU ترميز المصدر ويطبق الفلاتر، بينما يتولى GPU الترميز عند نجاح التجربة. هذا لا يعني الاستغناء عن CPU. لا يغير الاختيار التلقائي البروفايل المحفوظ، ويتجاهل Video Preset اليدوي أثناء الجلسة لاختلاف قيمه بين المعالج والكروت. محرك ErsatzTV next التجريبي لا يدعم فصل مراحل التسريع، ويطبق إعداداته الخاصة مع إظهار الإعدادات المتجاهلة. الفحص الأولي لا يضمن نجاح كل ملف أو استمرار توفر الكارت بعد بدء البث. وضبط Threads يقلل خيوط العمل؛ لا يضع حدًا صارمًا لنسبة استهلاك المعالج.

## الدخول بيوزر وباسورد

شغّل النسخة المبنية باستخدام أحد الملفين، وحدد مسار الملف التنفيذي:

```powershell
powershell -File scripts/start-xbest.ps1 -Executable .\tunarr.exe
```

```bash
bash scripts/start-xbest.sh ./tunarr
```

سيُطلب اسم المستخدم وكلمة المرور دون إظهارها أثناء الكتابة. لا توجد بيانات دخول افتراضية. تظهر نافذة الدخول الخاصة بالمتصفح عند فتح البانل، ويتحقق السيرفر من بيانات الدخول لكل طلب محمي، بما فيه طلبات الإدارة المباشرة. تستطيع الخدمات غير التفاعلية استخدام `TUNARR_BASIC_AUTH_USER` و`TUNARR_BASIC_AUTH_PASSWORD` بدل الإدخال. إذا ضُبط أحدهما فقط يرفض السيرفر التشغيل.

هذه حماية HTTP Basic موجودة في المشروع، وليست صفحة حسابات متعددة أو تسجيل مستخدمين. مسارات المشاهدة ودليل البرامج المعلّمة كمسارات عامة تظل متاحة للمشغلات؛ حماية روابط المشاهدة مطلب منفصل. استخدم HTTPS عند الوصول من خارج الجهاز، لأن Basic Auth يحتاج اتصالًا مشفرًا لحماية بيانات الدخول أثناء النقل.

تشغيل الملف التنفيذي مباشرة دون المتغيرين يبقي السلوك السابق دون تسجيل دخول. استخدم ملفات التشغيل أعلاه لتشغيل البانل المحمي.
